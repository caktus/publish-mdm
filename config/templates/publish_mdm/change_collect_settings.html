Notes

These settings are used to generate ODK Collect QR codes for app users assigned to projects using this configuration. See the ODK Collect docs for a full list of available settings.

The following fields are set automatically and cannot be set here:

  • general.server_url
  • general.username: will be set to the app user's name.
  • project.name: will be set based on the project name, app user's name, and general.app_language e.g. "project name: appuser (en)"
  • admin.admin_pw: can be added as a template variable.
