These settings are used to generate ODK Collect QR codes for app users assigned to projects using this configuration. See the ODK Collect docs for the full list of settings.

The following fields are set automatically and cannot be set here:

  • general.server_url — ODK Central URL with app user token.
  • general.username — app user's display name.
  • project.name — based on the project name, app user's display name, and general.app_language e.g. "Project: AppUser (en)".
  • admin.admin_pw — add an admin_pw template variable to set this.
